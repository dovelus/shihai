# Shihai - Incident Management and Monitoring
Shihai is monitoring and incident management solution made for growing teams who need felxability easy deploy and instant informations about the event that are happening,
It's targeted both to small businiess who want to manage infrastuctures events like resources usage to cybersecurity teams that want to have a central solution for their custom events. 
It's planned even a support for cybersecurity companies who manage multiple EDR solution and want a unified way to view, manage and resolve events.
